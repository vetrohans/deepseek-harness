# UI 插件迁移到新电脑教程

把本文件夹（`UI功能改动`）里的整套插件和修改搬到另一台 Mac。

## 一、一次性准备（新电脑上）

1. **安装 DeepSeek Harness**：和本机相同版本（`.app` 装到 `/Applications`）。
   > 布局补丁（对话居中、左对齐等）是就地修改 Harness 内部文件的，锚点依赖具体版本，版本差太多会导致补丁失败。
2. **安装 Node.js 20+**（含 npm/corepack，用来跑 pnpm）。没有的话脚本会提示。
3. **把整个 `UI功能改动` 文件夹拷过去**（U 盘 / AirDrop / 网盘都行，拷哪里都无所谓，脚本会自己放到正确位置）。

## 二、运行一键脚本（新电脑上）

```bash
cd UI功能改动
./migrate-to-new-machine.sh
```

脚本自动完成（约几分钟，需要联网下载依赖）：

| 步骤 | 做什么 |
|---|---|
| 1 | 检查 Harness 是否已安装 |
| 2 | 把项目部署到 `~/.dsh/UI功能改动`（不在那里时才拷贝） |
| 3 | 还原 profile 配置到 `~/.dsh/profiles/web/`（package.json / cordis.yml / cordis.patch.yml / lockfile） |
| 4 | `pnpm install` 安装 profile 依赖（dsh-notification 等） |
| 5 | 把 `dsh-better-sidebar` 换成指向本地项目的**符号链接**（默认装的是 github 官方版，不换的话你的改动不生效） |
| 6 | 构建 `dsh-better-sidebar`（`pnpm install && pnpm build`） |
| 7 | 打布局补丁 + 部署主 UI 插件（内部调用 `./dsh-ui.sh apply --no-restart`） |
| 8 | 重启 DeepSeek Harness |

跑完最后一步：浏览器打开 GUI（默认 `http://127.0.0.1:59767`），按 **Cmd+Shift+R 硬刷新**。

## 三、手动步骤（不想用脚本时）

```bash
# 1. 项目放到 ~/.dsh/UI功能改动（rsync 拷贝，排除 node_modules）
rsync -a --exclude node_modules UI功能改动/ ~/.dsh/UI功能改动/

# 2. 还原 profile 配置
mkdir -p ~/.dsh/profiles/web
cp UI功能改动/migrate/profiles/web/* ~/.dsh/profiles/web/

# 3. 安装 profile 依赖
cd ~/.dsh/profiles/web && pnpm install

# 4. 换成本地符号链接（关键！）
rm -rf ~/.dsh/profiles/web/node_modules/dsh-better-sidebar
ln -s ../../../UI功能改动/dsh-better-sidebar ~/.dsh/profiles/web/node_modules/dsh-better-sidebar

# 5. 构建 better-sidebar
cd ~/.dsh/UI功能改动/dsh-better-sidebar && pnpm install && pnpm build

# 6. 布局补丁 + 主插件部署 + 重启 GUI
cd ~/.dsh/UI功能改动 && ./dsh-ui.sh apply
```

## 四、各文件/目录的作用

| 路径 | 作用 | 迁移方式 |
|---|---|---|
| `lib/client.js`、`lib/index.js` | 主 UI 插件（余额胶囊、快速定位条、字体缩小、对话居中、审批卡片等） | 脚本第 7 步复制到 `~/.dsh/profiles/node_modules/@local/dsh-client-ui-preview/` |
| `dsh-better-sidebar/` | 右侧栏插件（完整源码 + 构建产物 `lib/`） | 符号链接到 `~/.dsh/profiles/web/node_modules/` |
| `apply-patches.py` | 布局补丁（就地改 Harness 内部 `dsh-client-ui-layout`，带备份） | 脚本第 7 步执行 |
| `dsh-ui.sh` | 维护脚本（apply / restore / watch / status） | 随项目拷贝 |
| `migrate/profiles/web/` | profile 配置（bundle 列表 + 插件挂载 + 依赖锁定） | 脚本第 3 步复制到 `~/.dsh/profiles/web/` |
| `migrate-to-new-machine.sh` | 一键迁移脚本 | 直接运行 |

**不会迁移的东西**（需要在新电脑上重新弄）：

- **API Key / 模型凭据**：在 DSH 设置里重新配置（`DEEPSEEK_API_KEY` 等）。
- **浏览器偏好**（localStorage）：侧栏布局记忆、开关状态等，重启后按默认值重新生成。
- **pnpm 依赖缓存**（`node_modules`）：不拷贝，到新机器重新 `pnpm install`（更稳，避免平台二进制不匹配）。

## 五、常见问题

**Q: 脚本报 `未找到 DeepSeek Harness`？**
A: 确认 `.app` 装在 `/Applications`，或设置 `DSH_APP_BUNDLE=/实际路径` 再跑。

**Q: 脚本报 `找不到 pnpm`？**
A: 装 Node.js 20+ 后执行 `corepack enable`，或手动 `npm i -g pnpm`，重开终端再跑。

**Q: 布局补丁失败（dsh-ui.sh 报 FAIL）？**
A: 多半是 Harness 版本和本机不一致，布局文件锚点对不上。装回相同版本后重跑 `./dsh-ui.sh apply`。

**Q: 打开 GUI 后界面还是老样子？**
A: 先硬刷新（Cmd+Shift+R）。若仍不对，运行 `./dsh-ui.sh status` 检查布局补丁/插件是否部署成功，再确认浏览器访问的是 `http://127.0.0.1:59767` 这个实例。

**Q: 之后改代码怎么同步？**
A: 和本机一样：改 `lib/client.js` 跑 `./dsh-ui.sh apply`；改 `dsh-better-sidebar/src/` 跑 `cd dsh-better-sidebar && pnpm build`，然后硬刷新即可（client 改动无需重启，host 半改动需重启应用）。
